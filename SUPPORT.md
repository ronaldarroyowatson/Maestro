# Support Guide

This document explains how to get help with Maestro during development.

## Getting Help

If you encounter issues:
1. Check the README.md for setup instructions.
2. Review the CHANGELOG.md for recent updates.
3. Look at the backend console for error messages.
4. Check the browser console for frontend errors.

## Common Issues

### WebSocket Not Connecting
- Ensure the backend is running.
- Verify you are accessing http://127.0.0.1:8000/ui
- Check firewall settings.

### Models Not Responding
- Ensure Ollama is running.
- Verify required models are installed.

### Pipeline Freezes
- Check backend console for stack traces.
- Restart the backend to reset threads.

## Asking Questions

When requesting help, include:
- What you were trying to do
- What you expected to happen
- What actually happened
- Backend console output
- Browser console output

## Feature Requests

Provide:
- A clear description of the feature
- Why it would be useful
- How it might work in Maestro
