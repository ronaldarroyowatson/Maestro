# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Instead, email the maintainer directly with details of the issue and the impact. Use the repository owner's public GitHub contact or the configured security contact for this project.

Please include:

- a clear description of the issue
- affected versions or commit hashes
- reproduction steps or proof of concept
- the impact and risk assessment
- any suggested remediation

## Review expectations

We will review and respond as quickly as possible. If the issue is valid, we will work to remediate it and coordinate disclosure timing with the reporter.

## Supported versions

The project is currently in an active development phase. Security fixes are handled on the current branch and the latest release line as applicable.
