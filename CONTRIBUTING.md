# Contributing to Maestro

Thank you for your interest in contributing to Maestro! This project is designed to be open, extensible, and educational. Contributions of all kinds are welcome — code, documentation, UI improvements, bug reports, and feature ideas.

## How to Contribute

### 1. Fork the Repository
Create your own fork of the Maestro repository on GitHub.

### 2. Create a Feature Branch
Use a descriptive name:

    git checkout -b feature/improve-websocket-logging

### 3. Make Your Changes
Follow these guidelines:
- Keep code clean and readable
- Use clear function and variable names
- Add comments where needed
- Avoid unnecessary complexity
- Maintain consistency with existing style

### 4. Test Your Changes
Before submitting:
- Run the backend
- Open the dashboard
- Verify that the agent pipeline still works
- Ensure no console errors appear

### 5. Commit Your Work

    git add .
    git commit -m "Describe your change clearly"

### 6. Push and Open a Pull Request

    git push origin feature/improve-websocket-logging

Then open a PR on GitHub with:
- A clear description of what you changed
- Why the change is needed
- Any screenshots or logs if relevant

## Reporting Bugs

Please include:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Backend console output (if applicable)
- Browser console output (if applicable)

## Feature Requests

Feature ideas are welcome! Provide:
- What you want to add
- Why it matters
- How it might work in Maestro

## Code Style

- Python: clean, readable, minimal magic
- JavaScript: simple, explicit, no unnecessary frameworks
- HTML/CSS: semantic and maintainable
- Comments: explain intent, not obvious code

## Thank You

Your contributions help Maestro grow into a powerful, open, local orchestration studio.
